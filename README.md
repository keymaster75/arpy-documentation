# ARPy – alat za bržu pripremu revizorskih PDF izveštaja

![Version](https://img.shields.io/badge/version-0.9.3-blue)

![Platform](https://img.shields.io/badge/platform-Windows-blue)

![Python](https://img.shields.io/badge/Python-3.12-yellow)

![Status](https://img.shields.io/badge/status-Active-success)

![License](https://img.shields.io/badge/license-Commercial-red)

ARPy je desktop aplikacija namenjena revizorskim društvima za automatizaciju pripreme završnih PDF izveštaja.

Omogućava objedinjavanje Word i PDF dokumenata, dodavanje memoranduma, potpisa i pečata, obradu priloga i generisanje finalnog dokumenta spremnog za predaju APR-u, klijentima i drugim institucijama.

---



## 🚀 Glavne funkcionalnosti

* 📄 Spajanje Word i PDF dokumenata u jedan izveštaj
* 🏢 Automatsko dodavanje memoranduma (header/footer)
* ✍️ Umetanje potpisa i pečata
* 📑 Generisanje finalnog PDF dokumenta
* 🔧 Profili za različite tipove revizorskih izveštaja
* 📋 Čarobnjak (Wizard) za vođenu pripremu kompletnog izveštaja
* 🔍 Kontrole kvaliteta i upozorenja pre kreiranja FINAL PDF-a
* 🛡 Word Quality Control (Word QC)
* 📑 FINAL PDF Quality Control (FINAL QC)
* 📂 Automatsko arhiviranje pomoćnih PDF fajlova
* 📦 Automatska provera novih verzija i jednostavan update postupak

---

## 🧠 Tipičan workflow

1. Učitavanje dokumenata:

   * Mišljenje revizora
   * Napomene
   * Obrasci
   * Prilozi

2. Automatska obrada:

   * memorandum
   * potpis i pečat
   * provera PDF dokumenata

3. Generisanje sadržaja

4. Kreiranje PDF priloga

5. Kreiranje FINAL PDF dokumenta

---

## 🛡️ PDF zaštite i kontrole

ARPy sadrži više mehanizama za smanjenje rizika od grešaka tokom pripreme izveštaja:

* upozorenje za zastarele priloge
* upozorenje za neusklađen PDF mišljenja
* detekcija rasterizovanih/skeniranih PDF dokumenata
* analiza veličine PDF fajlova
* kontrola promene broja strana tokom A4 konverzije
* selektivna rasterizacija potpisanih PDF strana radi očuvanja kvaliteta i veličine dokumenta
* Word Quality Control
* Opinion PDF Quality Control
* FINAL PDF Quality Control
* automatska provera A4 formata
* detekcija formularskih polja
* detekcija elektronskih potpisa

## 🆕 Najvažije novosti (0.8.x – 0.9.x)

Poslednje verzije ARPy-ja bile su usmerene na povećanje pouzdanosti,
kontrole kvaliteta i unapređenje korisničkog iskustva.

### PDF Workflow

- Selektivna rasterizacija digitalno potpisanih/formularskih PDF stranica
- Očuvanje vizuelnog elektronskog potpisa
- Napredna Fit A4 obrada
- Podesiva Strict PDF kompresija
- Arhiviranje pomoćnih PDF fajlova (_arpy_temp)

### Quality Control (QC)

- Word QC
- Opinion PDF QC
- Management Letter PDF QC
- FINAL PDF QC
- Jedinstveni QC Report Dialog
- Kopiranje rezultata
- Čuvanje QC izveštaja u TXT
- Direktno otvaranje analiziranog PDF-a

### Wizard

- Poboljšan workflow
- Batch Print unapređenja
- Auto redosled obrazaca
- Pamćenje korisničkih podešavanja
- Brojna UX poboljšanja
