# ARPy – alat za bržu pripremu revizorskih PDF izveštaja

ARPy je desktop aplikacija namenjena revizorskim društvima za automatizaciju pripreme završnih PDF izveštaja.

Omogućava objedinjavanje Word i PDF dokumenata, dodavanje memoranduma, potpisa i pečata, kao i generisanje finalnog dokumenta spremnog za predaju.

---

## 🚀 Glavne funkcionalnosti

- 📄 Spajanje Word i PDF dokumenata u jedan izveštaj
- 🏢 Automatsko dodavanje memoranduma (header/footer)
- ✍️ Umetanje potpisa i pečata na definisane stranice
- 📑 Generisanje finalnog PDF dokumenta
- 🔧 Profili (različita pravila za različite tipove izveštaja)
- ⚡ Brži workflow u odnosu na ručni rad u Word/Acrobat okruženju

---

## 🧠 Tipičan workflow

1. Učitavanje dokumenata (Mišljenje, Napomene, Obrasci)
2. Automatska obrada:
   - memorandum
   - potpis/pečat
3. Spajanje u jedinstven dokument
4. Export u finalni PDF
